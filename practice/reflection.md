# Git workflow reflection

Write at least one complete sentence for each answer. Each answer must contain at least 20 characters.

## 1. What is the difference between a commit and a push?

Answer: A commit saves the file as it is, while a download saves it onto your computer.

## 2. Why work on a branch instead of directly on `main`?

Answer: So, if something goes wrong, you will not have to go through the steps of re-creating the main file, you can just make another branch.

## 3. What does a pull request make possible?

Answer: A pull request connects the main file to whatever branch that is being worked on.

## 4. Which Git command helped you understand the repository's state, and what did it show you?

Answer: The fork command, and it helped me understand that even if editing one file is not possible, I can copy it and make my own changes to that copy.
